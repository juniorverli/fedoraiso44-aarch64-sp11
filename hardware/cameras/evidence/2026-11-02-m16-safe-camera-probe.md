## Captured graph

**Verified:** `/dev/media0`, `/dev/video0` through `/dev/video15`, and `/dev/dma_heap/system` exist; `ls` says `cannot access '/dev/v4l-subdev*': No such file or directory`. All 16 video nodes belong to `Qualcomm Camera Subsystem (platform:acb7000.isp)`. `media-ctl` lists subdevice entities `msm_csiphy0`, `msm_csiphy1`, `msm_csiphy2`, `msm_csiphy4`; `msm_tpg0`–`msm_tpg2`; `msm_csid0`–`msm_csid4`; `msm_vfe0_rdi0`–`msm_vfe0_rdi2`, `msm_vfe0_pix`, corresponding VFE1 names; and `msm_vfe2_rdi0`–`msm_vfe2_rdi3` and VFE3 equivalents. Sensor entities `ov13858 8-0010` and `imx681 9-0010` each have one source pad and **zero links**.

The video mappings are VFE0 `msm_vfe0_video0`–`3` = `/dev/video0`–`3`, VFE1 = `/dev/video4`–`7`, VFE2 = `/dev/video8`–`11`, VFE3 = `/dev/video12`–`15`. Each VFE RDI/pix source to its video node is `[ENABLED,IMMUTABLE]`. Every CSIPHY source has a link to each CSID sink, and each CSID source pad links to the corresponding RDI (or pix for VFE0/1 pad 4) on each VFE. These configurable internal links are `[]` (disabled), as expected before userspace configures a route. There is no sensor-to-CSIPHY link at all: the rear path is **not complete**, independently of those configurable links.

**Inference, strong:** unbound IR is preventing notifier completion. CAMSS enumerates every local endpoint and adds a remote match (`sources/linux/drivers/media/platform/qcom/camss/camss.c:4792`); the async core waits for all matches (`sources/linux/drivers/media/v4l2-core/v4l2-async.c:257`); CAMSS creates all sensor links and registers subdev nodes only in its complete callback (`camss.c:5183`). OF graph iteration does not filter by status (`sources/linux/drivers/of/property.c:752`). All three endpoints are described, two sensors bind, and the IR does not. This is consistent with the graph and explains `cam -l`; confirm by removing the IR graph in a new boot and observing the missing links and nodes appear. Disabling only the IR I2C node is insufficient. Failure of either RGB sensor to bind would similarly stall this all-or-nothing notifier; use the corrected rear-only variant to isolate.
